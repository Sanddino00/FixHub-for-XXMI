You need python for the scripts
Please check out the original creators of the fix tools and support them if possible. I included the links to the original download pages in the credits section.

Usage:

Select the mod folder for each game you want to use this for in the settings.
Then using it select a folder via the CHoose run path button, selet a fix and click run.
Depending on the fix it will either open a terminal window or an exe. Follow what the fix tells you
After it finishes you can close the terminal/exe and select next folder to fix or next fix to use

Resources:

These are fix tools from different creators for Genshin, Star Rail, Wuwa etc. You can get them all on Gamebanana and Github.

The tools included are for updating the character hashes and/or fixing reflection issues etc and to save your toggle choice

Important:
Depending on if you downloaded the resources.zip containing the newest fixes to my knowlege or got them yourself you need to create a folder named resources in the same folder the exe . In the resources folder make  5 subfolders called: gi, hsr, wuwa, zzz, hi3 and place your fixes in the right folder.
